# Earth texture credits

- `earth_day_4096.jpg`, `earth_day_1024.jpg`: NASA Blue Marble (Next Generation) composite, via the `three-globe` npm package example images (MIT). NASA imagery is public domain. Recompressed to JPEG; the 1024 copy is a downscale used for the no-WebGL fallback.
- `earth_bump_2048.jpg`: NASA/NOAA-derived topography grayscale from `three-globe` example images (MIT; underlying data public domain). Converted to JPEG.
- `earth_specular_2048.jpg`, `earth_clouds_1024.png`: three.js examples (`examples/textures/planets`, MIT licence, https://github.com/mrdoob/three.js). Based on NASA public-domain data.

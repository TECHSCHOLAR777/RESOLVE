## Local Development

### Prerequisites

- **Node.js** ≥ 18

### Setup

```bash
# 1. Clone
git clone https://github.com/TECHSCHOLAR777/RESOLVE.git
cd RESOLVE

# 2. Install dependencies
npm install

# 3. Start dev server
npm run dev
# → http://localhost:3000
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
